# Snow Bros — Java Game

A simplified 2D platform game inspired by the classic arcade game **Snow Bros (1990)**, developed in Java as a collaborative university project.

## About the Project

This project was developed as part of the course **Programming Technology (Tecnología de Programación)** during the second semester of 2025 at **Universidad Nacional del Sur (UNS), Argentina**.

The goal was to design and implement a simplified version of Snow Bros, recreating its main gameplay mechanics while introducing different visual themes, game modes, enemies, power-ups, obstacles, and interactive elements.

Players control a snow character whose objective is to defeat enemies by throwing snowballs, freezing them, and pushing them across the level.

## Features

- **Multiple Visual Domains:** Different visual themes with distinct character designs and environments.
- **Three Game Modes:**
  - Classic: Defeat all enemies in each level.
  - Time Attack: Complete levels within a time limit.
  - Survival: Face continuous waves of enemies.
- **Multiple Levels:** Increasing difficulty, loaded from external text files.
- **Enemy Variety:** Different enemy types with unique behaviors and interactions.
- **Power-ups:** Collectible items providing temporary abilities and bonuses.
- **Interactive Environments:** Platforms, obstacles, destructible elements, and traps.
- **Boss Battles:** Special enemies with unique attack patterns.
- **Scoring System:** Points awarded for defeating enemies and collecting items.
- **Persistent Leaderboards:** Top 5 player rankings for each game mode.
- **Sound Effects:** Audio feedback for in-game actions and interactions.

## Technologies

- **Java** — Core programming language.
- **Java Swing** — Graphical user interface and rendering.
- **Multithreading (Threads)** — Character movements and visual transitions.
- **Object-Oriented Programming** — Game architecture and entity modeling.
- **Design Patterns** — Application of creational and behavioral design patterns.
